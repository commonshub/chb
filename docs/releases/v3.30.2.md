# v3.30.2 — reconcile plans refuse stale invoices/bills

A reconcile plan (`chb odoo journals <id> reconcile`, dry-run or live, and
the hourly sync's reconcile phase) reads payment states from the local
invoices/bills cache. It now refuses to plan when that cache was last
pulled more than 3 hours ago ("run `chb odoo pull` first"). `chb odoo
pull` stamps a per-database cursor after each successful invoices and
bills pull; before the first stamp the cache files' fetchedAt is used.
The apply step already re-checks each document live (an already-paid
document is never re-attached by a batch run).
