# v3.33.0 — membership reminders

- `chb members remind`: one email per status change (grace: payment
  failed or paused; lapsed in the last 30 days), from the website's
  templates, with a signed renew link (`RENEW_LINK_SECRET`), sent through
  Resend (`RESEND_API_KEY`). Preview by default, `--yes` to send, a ledger
  so nothing is sent twice, at most 25 per run. `--render-test` prints a
  sample. Not in the cron yet. See [members.md](../members.md).
- `chb generate` writes the plan (stewards-only, no addresses).
- The Odoo membership snapshot keeps each invoice's structured
  communication; Stripe snapshots keep the customer id (both stewards-only).
