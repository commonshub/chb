# v3.30.3 — reference matches must settle the document exactly

A bank line whose text names an invoice or bill is applied automatically
only when its amount equals the document's open residual (±0.01).
Otherwise — partial payment, over/under payment, a document already paid —
the match goes to `reconcile -i`, which shows the difference ("reference
match, amounts differ: payment X, open Y (difference Z)"). Amount-only
matches keep their review note too. The interactive suggestions are
filtered by direction (document type) as well.
