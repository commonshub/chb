# v3.28.0 — tokens issued feed

- `YYYY/MM/<tier>/tokens-issued.json` and `latest/<tier>/tokens-issued.json`
  (last 60 days): every mint of the contribution token, newest first —
  timestamp, amount, recipient (Discord id + display name, from the
  wallet → Discord map; null when unlinked), reason and kind from the
  token bot's Nostr annotation (trusted authors only; the "Issued N CHT to
  <user> for" prefix dropped), and the Discord link (`r` tag).
- No transaction id or wallet below stewards; stewards get both. Excluded
  mints are left out. Every month has the file; unchanged months are not
  rewritten.
- Docs: website.md §15, audiences.md.
