# v3.21.0 — annual accounts: unknown filing dates, NBB register, internal figures

- `chb annual-accounts set <year> --filed` without a date marks a fiscal
  year filed with `filedAt: null`.
- `--figures-source internal-balance` (import or set): the figures
  (`figures.csv`) are class totals read from the accountant's internal
  balance sheet; published with an info check saying so, while the internal
  document itself stays stewards-only.
- `chb pull` checks the association's deposits on the NBB register
  (consult.cbso.nbb.be) once a day. A filed fiscal year not yet on the
  register gets the info check `not-on-nbb-register` ("not yet visible on
  the NBB register as of <date>"); once it appears, the deposit date and
  reference fill in `filedAt` and `nbb.reference`. `nbb` is always present:
  `url` (the deposit or the association's register page), `onRegister`,
  `checkedAt`, `depositedAt`.
- Fix: the register snapshot in the drop folder is not imported as a
  document.
