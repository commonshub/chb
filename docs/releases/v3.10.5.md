# v3.10.5 — live-balance check compares summed journal lines

The Odoo-vs-live balance check read Odoo's journal-level
`current_statement_balance`, which can lag the statement lines by a few
cents (a line outside any statement). Against the summed lines — the basis
of the "Journal data:" summary and of the local mirror — this produced a
phantom −0.65 EUR "journal drift" on every hourly run for the Stripe
journal. The check now sums the lines, so a reported drift is a real one.
