# v3.33.4 — config.env keeps every key

Saving `config.env` (chb setup, setup odoo, and the membership pull's
salt) rewrote the file with only the keys the setup wizard knows, dropping
everything else: RESEND_API_KEY and RENEW_LINK_SECRET added by hand were
erased, and EMAIL_HASH_SALT itself was never kept — so a new salt (and new
email hashes) was generated on every hourly run. Unknown keys are now kept,
sorted after the known ones.
