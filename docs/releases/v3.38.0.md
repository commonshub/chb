# v3.38.0 — stewards classify money; token categories

- Annotations: `category`, `collective`, `spread` and `exclude` count only
  from seeds, the keys they follow (bots) and steward-attested keys
  (`nostr.categoryRoles`, default `steward`). Members' annotations keep
  their note, event and tags. Applies to transactions, Odoo documents and
  spreads (which had no trust check at all).
- Stripe transactions take annotations made on their published id
  (`stripe:txn_…`) as well as on the charge (`stripe:ch_…`); the newest
  wins. Before, `stripe:txn_…` annotations were not applied.
- categories.json: token categories (group `contributions`): governance,
  cleaning, shift, note-taking, admin, care, none.
- bookings.json `payment`: a "Booking TX:" line means tokens.
- Categories check: a burn with a note counts as described.
- Docs: annotations.md.
