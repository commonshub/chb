# v3.29.1 — fix the vendor-reference search

v3.29.0 (never deployed) built the vendor-reference OR clause with the
wrong number of `|` operators, so Odoo rejected the search for any bank
line with two or more numbers in its text, and the error stopped the
partner match that follows. Found by a read-only dry-run of the new
matching on commonshub-test (73 unreconciled lines: no errors, nothing
reconciled or held after the fix).
