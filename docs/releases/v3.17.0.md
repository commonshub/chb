# v3.17.0 — every month has the same files; latest/ fixed

**Same files everywhere.** `chb generate` ends with a "Month file set"
step: from the first month of data to the last, every month gets every
month file in every tier, and every year every year file. A tier copy
missing although the stewards file exists is re-projected offline;
past months generated before the tier split thereby get their public
`events.json` back. A month with no data gets an empty, schema-valid file.
See `docs/website.md` §2 for the list.

**`latest/` bug fixed.** Year files were mirrored to `latest/`, so
`latest/<tier>/contributors.json` (top contributors) and
`activitygrid.json` (every year) were overwritten by the last year
processed. On prod that was the empty 2027 file. Only month files mirror
now; `latest/events.csv` is written explicitly as the current year's sheet.

The month `bills.json` stays retired: the bills are `kind: "bill"` entries
of `expenses.json`; `latest/<tier>/pending-bills.json` is the "still to
pay" view.

Includes PR #18 (Friedger): sole traders' free text and event tags and
person-naming `counterpartyId`s no longer reach `public/`.

Run `chb generate --history --force` once after upgrading.
