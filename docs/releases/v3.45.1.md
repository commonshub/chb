# v3.45.1 — members.json: members tier keeps emailHash

The members tier of `members.json` now keeps `accounts.emailHash` (the
salted email hash; not reversible without `EMAIL_HASH_SALT`). It had been
blanked there since the audience-tiers refactor (2026-09-16); the
website matches a member's dashboard plan by it. Stripe links, payment
urls, Odoo ids and mismatches stay stewards-only; public is unchanged.
