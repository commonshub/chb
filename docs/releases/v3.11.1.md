# v3.11.1 — the tier policy also catches lower-case IBANs

Canonical URIs carry IBANs in lower case (`iban:be68…`). The write-time
policy for `public/` and `members/` only matched upper-case candidates; it is
case-insensitive now. No leak was found on prod (the only lower-case IBAN in
those tiers is our own account's URI, which is allowed), but the guard must
not depend on casing.
