# v3.25.0 — trust members' keys attested by the website

- A key that a trusted seed attests (kind 31926, `p` tag) is trusted for
  annotations, when the attestation carries an allowed role
  (`nostr.attestationRoles`, default `member` and `steward`, from `role`
  tags or the content's `roles`) and names our Discord guild (`i` tag,
  when `discord.guildId` is set). One level, signatures checked,
  refreshed at each pull with the follows; a newer attestation without
  the key or the role revokes it. `nostr.trustAttestations: false` turns
  it off. trust.json records the attested keys.
- Docs: [annotations.md](../annotations.md) "Who is trusted".
