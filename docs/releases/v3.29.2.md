# v3.29.2 — drift measured on the books

The journal drift check (Odoo vs on-chain / Stripe) compares with the
posted balance of the journal's bank account instead of the sum of its
statement lines. Migrated journals (an opening line plus the history it
restates, restatement entries booked on the account) no longer report a
false drift; the statement-line sum is shown as a hint next to a real
drift. The post-push "Odoo journal balance ≠ local" note is silent when the
ledger matches. Monitoring only: nothing is written to Odoo. Tested on
commonshub-test: only journal 50 (multisig) differs — statement lines
9,089.19, ledger 0.00 = on-chain.
