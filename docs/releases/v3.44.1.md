# v3.44.1 — Reconcile: payments that name a document they don't pay

- A memo naming an invoice/bill that another payment already settled is
  review-only up front (it was a batch "winner" that failed at apply).
- The closing report of `chb odoo sync` / `chb sync` now lists every bank
  line whose memo names an invoice/bill it is not matched with:
  - still open: the line is unmatched and the document open;
  - paid by another payment: a double payment, or that other match is
    wrong (CHB/2026/00253 paid twice);
  - still open, line already matched: the line pays another document, or
    only part of this one (RadicalxChange's €200 attached to
    MEM/2026/00074 while its structured communication named 2026_RCC_28).
