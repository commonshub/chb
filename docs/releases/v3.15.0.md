# v3.15.0 — richer integrity manifests, reproducible outputs

`hashes.json` now records the `chb` build that wrote it
(`"chb": {"version", "commit"}`) and, next to the raw-data hashes, hashes
of the month's processed `public/` and `members/` trees (`tiers`). The
index `latest/hashes.json` adds the same `chb` block, the tier hashes per
month, and a top-level `hash` over every month: one value to compare a
whole dataset. Tier hashes match across instances running the same
version with the same raw data and settings.

A manifest is rewritten only when a hash or the version changes, so
`generatedAt` marks the last real change instead of the last hourly run.

`generate` output is now reproducible byte for byte (after dropping
`generatedAt`): ties in the members, contributors, top contributors,
yearly users, images and transactions sorts are broken by id instead of
map order. Months are deliberately not chained; see docs/website.md §4.
