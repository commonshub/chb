# v3.46.0 — members.json: cancelsOn

Each member in `members.json` carries `cancelsOn` (YYYY-MM-DD) when their
Stripe subscription is set to cancel at period end (Stripe `cancel_at`,
else `current_period_end`), and `null` otherwise. It is set on the member
whichever source the entry comes from (Odoo or Stripe), so a member who
cancels from the website dashboard sees "you stay a member until X" after
a restart too. Taking the cancellation back clears it at the next pull.
