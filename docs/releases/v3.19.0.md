# v3.19.0 — annotation guide, trust through follows, Odoo consolidation

## How to annotate

New `docs/annotations.md`: the difference between an annotation (kind 1111,
lowercase `i`/`k` only: data chb applies) and a comment (uppercase `I`/`K`,
NIP-22: a discussion chb never applies), which URI to use for an on-chain,
Stripe or bank transaction and for a bill, credit note, invoice or expense
claim, the tags (`category`, `collective`, `event`, `spread`, note), and how
to publish (website, `chb nostr annotate`, any Nostr tool).

New command `chb nostr annotate <uri> [--category] [--collective] [--event]
[--spread YYYY-MM:amount] [--note] [--clear] [--dry-run] [--yes]`: starts
from the current trusted annotation, previews the event, publishes to the
configured relay. Bank transaction URIs now get `k = iban:tx`.

## Trust through follows

An author followed (kind 3 contact list) by a trusted seed
(settings.json `nostr.trustedAuthors`, plus this instance's key) is trusted
too: one level, signatures checked, refreshed at every `chb pull` into
`latest/providers/nostr/trust.json`. Unfollowing revokes at the next pull.
`nostr.trustFollows: false` turns it off.

## Odoo as the consolidated source of truth

- `chb odoo annotations push [--dry-run] [--yes]`: writes trusted
  annotations not yet applied as analytic distributions on bills, credit
  notes, invoices, booked expense claims and KBC journal lines. It only
  touches annotated records.
- `chb bills|invoices push` and `chb odoo journals <id> categorize` also
  take trusted annotations into account (v3.18 had stopped feeding them to
  bills/invoices).
- Each annotation is applied once (ledger
  `latest/providers/odoo/<db>/annotations-applied.json`): a later change
  made in Odoo wins until someone annotates again.
- `chb nostr push bills|invoices` now publishes Odoo's categorisation
  whenever it differs from the newest trusted annotation (all months, not
  only the current one), and waits while an annotation is not yet applied.
- Transactions in journals chb feeds were already consolidated by the
  hourly `chb odoo sync`.

`chb odoo annotations push` is not in the hourly job yet: add it to the
cron line to make the consolidation automatic.
