# v3.41.1 — recap: Discord links from the website

`chb members recap` now also links members to Discord ids through the
website's `GET /api/members/discord-links` (Bearer RENEW_LINK_SECRET):
Discord logins of members and membership applications, each with the
member's email hash (sha256(lowercase(trim(email)) + EMAIL_HASH_SALT), the
same as `accounts.emailHash`). No emails cross.

Order: the stewards' `settings/members-discord.json` first, then
`accounts.discord`, then the website link matched on the email hash. A hash
linked to two different Discord ids is ambiguous and skipped. The preview
shows how many links came from each source.
