# v3.30.1 — reconcile hotfix: direction, amount-only, verification

On 2026-10-05 the 20:00 run "reconciled" a €0.41 Stripe fee (line 40669)
with a KBC vendor credit note: two debits, so Odoo created no match, but
chb had already rewritten the counterpart to 440000, set the partner, and
reported "1 line reconciled".

- Direction by document type: an outgoing bank line can settle only a
  vendor bill or a customer credit note (in_invoice, out_refund); an
  incoming one only a customer invoice or a vendor credit note
  (out_invoice, in_refund). Before, a vendor credit note counted as a
  "bill" for outgoing lines.
- Amount-only matches (no reference, partner or name in common) are never
  applied by a batch run; `reconcile -i` asks.
- Same-side pairs are refused before any write; after reconcile, chb
  checks Odoo created a match and otherwise restores the counterpart
  account and reports an error (no partner attribution).
