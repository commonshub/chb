# v3.10.2 — pace explorer requests, honour Retry-After

First prod run of v3.10.1 fired 16 back-to-back Gnosis queries (8 accounts ×
2 EURe contracts, 400 ms apart) at Blockscout, which throttled the last 6
with HTTP 429; the retry waited a fixed 2 s three times and gave up.

- Requests to the same explorer are now spaced (Blockscout 1.2 s, Etherscan
  250 ms — its free plan allows 5 req/s).
- A throttled request waits `Retry-After` when the explorer sends it,
  otherwise 2 s doubling per attempt (cap 30 s), up to 5 attempts.
