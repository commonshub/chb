# v3.10.3 — live within the Gnosis explorer's 10-requests-per-hour budget

`gnosis.blockscout.com/api` redirects to `gnosisscan.io/api`, which allows
**10 requests per hour per IP** unauthenticated (`x-ratelimit-limit: 10`,
`x-ratelimit-reset` in ms). The hourly pull was making 16 (9 Gnosis accounts,
4 of them archived, × live + retired EURe contract) and then retrying each
refusal five times with up to 30 s backoff — a 13-minute pull that still failed.

- **Quota awareness.** When an explorer reports an empty bucket (a 429 whose
  reset is more than a minute away, or a 200 with `x-ratelimit-remaining: 0`),
  the run remembers it and fails fast for that explorer instead of retrying.
- **Routine runs skip archived accounts** (nothing can change there) and
  **poll retired prior contracts once a day**. `--slug` / `--force` still
  fetch everything. Budget per hour on Gnosis: 5 live accounts + at most 3
  daily prior-contract polls = 8.
