# v3.31.1 — members pull fetches; the email-hash salt is never printed

- `chb members pull` now fetches membership data, as the help says (it
  only printed statistics; `chb members sync` still works, `chb members`
  shows the statistics).
- When no `EMAIL_HASH_SALT` is configured, the generated salt is saved to
  config.env but no longer printed (the hourly pull's output goes to the
  cron log).
