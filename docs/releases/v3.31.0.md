# v3.31.0 — members back in the hourly pull; activity photos public

- `chb pull` (the Stripe provider) also runs the membership pull: the
  month's Stripe subscriptions and Odoo memberships snapshots
  (`providers/stripe|odoo/subscriptions.json`). Without them, every
  month's `members.json` was an empty skeleton on servers that never ran
  `chb members pull` by hand. Backfill once with `chb members pull
  --backfill`, then `chb generate --history`.
- Photos from #potluck, #heartbeat and #park-cleaning are public (added to
  the default `discord.publicChannels`), so their copies land in
  `YYYY/MM/public/images/` and `images.json` for /community.
