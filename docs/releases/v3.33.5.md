# v3.33.5 — never generate the email-hash salt

The membership pull no longer generates an `EMAIL_HASH_SALT` when none is
configured: it fails, loudly ("EMAIL_HASH_SALT is not set …"). The salt is
shared with the website, and a new one silently re-identified every
member. On 2026-10-06 the original salt was restored and every month's
membership snapshots were re-pulled with it.
