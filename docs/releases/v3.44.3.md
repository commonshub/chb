# v3.44.3 — Discord partners: website checkout links are reviewed

The website records a Discord link with source `checkout` when a member pays
from their dashboard (Stripe checkout with `client_reference_id =
discord_<id>`). Its email was typed at Stripe and never verified, so like a
`name` link it never writes `x_discord_id` on its own: the member is listed
for review with the partner(s) it points to. Member recaps use it as any
other link (it stands for that subscription).
