# v3.10.6 — folded ICS lines, room-booking dedupe, readable provider dirs

- **ICS parser appends folded continuation lines.** RFC 5545 folds any
  content line longer than 75 octets; the parser skipped the continuation
  lines, so every description stopped at 63 characters and long URLs were
  cut mid-way (`https://lum`). On the website that showed as raw
  `<a href="lum` fragments on event cards.
- **A Luma event and its room booking are one event.** Dedupe now matches
  on (URL, start day) instead of exact times, since the booking behind an
  event routinely ends later. "Building an AI Commons for Brussels NGOs"
  no longer shows twice.
- **Provider directories are created 0755, not 0700.** The website runs as
  another user and could read `generated/` but not `providers/`, which hid
  the Odoo bills, the quarterly reports and `/contribute` on production.
