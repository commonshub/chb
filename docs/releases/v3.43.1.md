# v3.43.1 — Discord partners: website name links are reviewed

The website's Discord links now carry a `source`: `login`, `email` (address
confirmed with a code) or `name` (the member confirmed a name match). Login
and email links link a partner as before; a name link never writes
`x_discord_id` on its own: the member is listed for review with the
partner(s) it points to, to confirm by hand in `members-discord.json`.
Member recaps use all three.
