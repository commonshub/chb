# v3.12.0 — integrity manifests per month

Every completed month now gets `integrity.json` in all three tiers: one entry
per provider archive (Odoo per database namespace) with counts, size and a
sha256 content hash, plus the month hash across providers.
`latest/<tier>/integrity.json` indexes every month. Instance-independent by
construction (canonical JSON, fetch timestamps dropped, Odoo outbox excluded)
so two instances can compare hashes to know they hold the same raw data;
hashes reveal nothing, so the manifests are public.

Written at the end of `chb generate` for months that have none yet or whose
providers changed since; `chb integrity [YYYY/MM] [--force] [--json]` prints
or recomputes them. New consumer reference: `docs/website.md`.
