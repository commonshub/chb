# v3.55.0

- `chb members recap` now covers every active and grace member, not only those linked to a Discord account. Members without a Discord id get the website's community recap (`/api/recap?emailHash=&name=`), which has a "Link my Discord account" button. Their preferences are read under `e:<emailHash>` and their ledger key is `e:<emailHash>:<period>`.
- Nobody gets the same period twice, even after linking Discord in between: a send under either key skips the member for that period.
- When one person has two memberships, they get one recap: the Discord one when either membership is linked.
- `--send-test <email> --email-hash <hash> --name <first>` sends the no-Discord version.
- The preview shows the active/grace total, how many have a Discord id, how many don't, and how many have no email address.
