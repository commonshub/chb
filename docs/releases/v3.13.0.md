# v3.13.0 — VAT declarations

New manual source: the periodic VAT returns filed with the Belgian State
through Intervat. `chb vat import <files|dirs>` (or the drop folder
`latest/providers/intervat/`) archives each XML export unchanged as
`YYYY/MM/providers/intervat/<statementId>.xml`, under the last month of its
period. `chb vat` lists the periods.

`chb generate` (and every import) writes the public `latest/vat.json` and
`YYYY/vat.json`: per period, every grid amount, the control totals (output
VAT, input VAT, net paid or refunded, consistency check against grids
71/72) and every filing, with corrections superseding earlier filings. Like
`hashes.json`, the file is identical for every audience, so it lives once
outside the tiers. The filer's email, phone and street address stay in the
raw archive. Consumer documentation: `docs/vat.md`, linked from
`docs/website.md`.

Also: the `intervat` entry in `hashes.json` counts declarations, and
`chb integrity` / `chb vat import` are listed in `chb --help` (the
integrity line had landed in the doctor help by mistake).
