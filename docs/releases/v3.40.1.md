# v3.40.1 — token fine print in rooms.md

Paying with tokens is not the euro service (VAT). Wherever a token price is
published, it now carries the website's fine print, verbatim from
`src/lib/token-terms.ts` (commonshub/commonshub.brussels):

- Each room's "Token price" line in `latest/<tier>/rooms.md` is followed by
  "Rooms booked with tokens: only when capacity is idle, subject to
  community activities, without cleaning or stewarding."
- A new "Paying with tokens" section under Booking states both terms, the
  room one and "Contributor coworking (with tokens): use an available desk
  when capacity is idle; no guaranteed desk, no advance reservation,
  subject to community activities."

rooms.md is the only file chb publishes that prices things in tokens (the
`chb rooms` table is terminal-only).
