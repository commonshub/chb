# v3.45.0 — members.json: masked email hint

Members and stewards tiers of `members.json` carry `accounts.emailHint`, a
masked version of the member's email: first character, "…", "@" and the
full domain (`x…@gmail.com`; `…@gmail.com` for a one-character local part).
The website's "Is this your membership?" card uses it to show which address
a membership is on without revealing it. Never in the public tier.

Computed at pull time from the Stripe customer email or the Odoo partner
email; the next `chb members` pull fills it in.
