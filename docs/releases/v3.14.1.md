# v3.14.1 — VAT drop folder imported by `chb pull`

`intervat` is now a pull provider: `chb pull` (and so the hourly job)
archives any declaration dropped in `latest/providers/intervat/` and
republishes `vat.json`. Before, files dropped there waited for a manual
`chb vat import`. A file that cannot be imported stays in the folder and
shows as a warning on the pull row.
