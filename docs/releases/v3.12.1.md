# v3.12.1 — one hashes.json per month

The integrity manifest introduced in v3.12.0 is public data, so it no longer
needs a copy in each audience tier. It now lives once at the month root as
`YYYY/MM/hashes.json` (0644, next to `public/`, `members/`, `stewards/`),
and the index of every completed month is `latest/hashes.json`. The first
`chb generate` or `chb integrity` after upgrading removes the v3.12.0
per-tier `integrity.json` copies. Content and algorithm are unchanged.
