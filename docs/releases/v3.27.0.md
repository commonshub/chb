# v3.27.0 — #contributions feed

- `YYYY/MM/<tier>/contributions.json` and `latest/<tier>/contributions.json`
  (last 60 days), identical in every tier: the #contributions messages,
  newest first — id, timestamp (UTC), author and mentioned users (Discord
  id + display name, bots dropped, deduped), total reactions, and the
  public photo copies. No message text. Written only while #contributions
  is one of `discord.publicChannels`; every month has the file (empty when
  there is nothing). Unchanged months are not rewritten.
- Display names that are email addresses fall back to the username.
- Docs: website.md §14, audiences.md.
