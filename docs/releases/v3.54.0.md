# v3.54.0

- A vendor bill whose payment is blocked in Odoo (the "Block payment" button, payment status `blocked`) is now shown as disputed: in `pending-bills.json` it has `status: "disputed"` and `disputed: true`, it stays in the list but out of `totals`, and a new `disputedTotals` sums the disputed bills. In `expenses.json` its status is `disputed`.
- Before, a blocked bill was shown as `pending` and stopped being refreshed from Odoo; bill sync now keeps refreshing blocked bills.
- First use: the three Arca Fiduciaire bills (CHB-S/2026/04/0020, CHB-S/2026/05/00005, CHB-S/2026/06/0018, €7,811.32), blocked in Odoo on 2026-11-17 because the promised work was never delivered.
