# v3.48.0 — public copy of each VAT declaration XML

- `chb vat import` and `chb generate` write `YYYY/MM/public/intervat/<statementId>.xml`
  for every archived Intervat filing (superseded ones included): the original
  bytes with only the filer's `<EmailAddress>` and `<Phone>` removed. `MM` is the
  period's last month, like the raw archive. The copy must still parse and passes
  the public tier policy before it is written (0644).
- `vat.json` gains `filings[].xml`, that copy's path relative to `DATA_DIR`.
