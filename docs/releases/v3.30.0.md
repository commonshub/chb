# v3.30.0 — real log indexes for transactions with several transfers

- The pull reads the transaction receipt of every on-chain transaction
  with several transfers of one account and stores each transfer's real
  log index in the archive (`logIndex`); older months are backfilled once.
  A receipt is fetched only for such transactions, only once.
- Generate deduplicates on (hash, log index) when it is known: two
  identical transfers in one transaction (two 4.15 mints) are both kept;
  the same event listed twice (EURe V1/V2) is still dropped. The archive
  merge keeps identical transfers too.
- Odoo import ids are never renamed: a transfer of such a transaction
  takes the id of the existing Odoo line it matches (exact `:log<N>`, then
  same amount in line order) — including hand-made ids — and a transfer
  without one gets `<chain>:<account>:<hash>:log<N>`. Extra Odoo lines are
  left alone.
- Fridge (EURb): local balance 21.50 = on-chain (was 7.52); tested on
  commonshub-test: no line would be created or re-imported on any on-chain
  journal.
